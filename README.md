# Create Ambient Music with Python

> "Some days ago, I had the idea of making ambient music using Python. So, I made it with my teacher called ChatGPT. I debugged some things and... that is the code 🧑‍💻✨"

---

## Tech Stack
* **Language:** Python
* **Libraries:** numpy, soundfile
* **Concepts:** Sine wave synthesis ('np.sin'), Drone chords, LFO (Low-Frequency Oscillator) for amplitude modulation.

---

##  How it works
This script generates a 60-second procedural ambient drone audio file (`ambientmusic.wav`) at 44.1kHz. It layers multiple frequency stacks (`[55, 110, 220, 440] Hz`) and applies an LFO to make the volume "breathe", creating an immersive soundscape from pure math.
